UX upgrades in this demo (beyond color)

Works right now

  • ⌘K command palette — keyboard-first navigation (press ⌘K / Ctrl+K). Biggest single power-user win.
  • Hover row actions — Open/⋯ buttons appear on hover; less visual noise, faster scanning.
  • Density toggle — try the Density button; traders want compact, admins want airy.
  • Sparklines in KPIs — trend context without a chart page.
  • Skeleton shimmer row — how loading should look instead of spinners.

Direction A · Midnight Deck

  • Dark glass + amber glow; ambient gradients give depth without noise.
  • Active nav = gradient wash + left accent bar; clear "you are here".
  • Best match with the existing marketing tokens — cheapest migration.

Direction B · Swiss Light

  • Flat, hairline, typographic. Status = outlined mono-color pills.
  • Feels premium/calm; great for print-like exports and reports.

Direction C · Terminal Pro

  • Maximum density: mono numerics everywhere, colored row edge-ticks.
  • Bloomberg energy — ideal for the trading desk audience.

Direction D · Soft Studio

  • Linear/Attio-style: elevated cards, tinted sidebar, pastel pills.
  • Friendliest; good if onboarding smaller/broker clients.

Next-level ideas (not in mock yet)

  • Split-view order detail (list + inspector pane) instead of full page nav.
  • Optimistic inline status changes (drag between columns / dropdown in row).
  • Saved views per user (filters + columns) with shareable URLs.
  • Toast + undo for destructive actions; empty states with one-click setup.
  • Real-time price cells with subtle flash-on-change animation (WS already exists).

Recommendation: A for the shell + D's KPI cards + C's row density as a toggle. All four share one token layer, so a hybrid is cheap.
